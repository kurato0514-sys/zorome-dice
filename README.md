# ゾロ目ダイス

サイコロを振ってゾロ目を出すたびに、サイコロが1個ずつ増えていく（最大15個）育成型ダイスゲーム。HTML/CSS/JSのみで動くPWA（スマホのホーム画面に追加してアプリのように使えます）。

## ローカルで動かす

ブラウザで直接 `index.html` を開くとPWA登録などが一部動かないため、簡易サーバー経由での確認を推奨します。

```
powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1
```

その後 `http://localhost:8532/` を開いてください。

## 主な機能

- 2個のサイコロから開始し、ゾロ目が揃うたびに1個ずつ解放（最大15個）
- 現在の確率表示・ステージごとのタイムアタック計測
- ステージ5・10・15到達でサイコロ＆お皿のデザインを解放
- リーチ演出、激アツ予告演出（複数パターン）、確定演出
- 本体を振ってサイコロを振る操作（対応端末のみ、設定でON/OFF）
- ストア画面（広告非表示・デザイン/サウンド/演出パックの購入）※現状はテスト用のモック
